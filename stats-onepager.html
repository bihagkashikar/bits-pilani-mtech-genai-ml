Concept / Model Core Definition Trigger Words & Phrase Clues Key Formula(s) Golden Rule / Decision Test
Event
Mutually Exclusive 		Events cannot happen at the same time. Overlap is non-existent. "cannot occur together", "either A or B (never both)", "disjoint" $$P(A \cap B) = 0$$ $$P(A \cup B) = P(A) + P(B)$$ If $A$ occurs, $B$ is impossible ($P(B \mid A) = 0$).
Event
Independent Events 		Occurrence of Event $A$ has zero effect on the probability of Event $B$. "with replacement", "tossing multiple coins", "unaffected by" $$P(A \cap B) = P(A) \cdot P(B)$$ $$P(B \mid A) = P(B)$$ Test equality: $P(A \cap B) \overset{?}{=} P(A)P(B)$.
Event
Dependent Events 		Occurrence of $A$ alters/changes the likelihood of $B$. "without replacement", "successive draws", "finite deck/jar" $$P(A \cap B) = P(A) \cdot P(B \mid A)$$ $P(A \cap B) \neq P(A)P(B)$. Second draw count/odds change.
Event
Conditional Probability 		Probability of $B$ given that condition/event $A$ has already occurred. "given that", "knowing that", "among those who", "if" $$P(B \mid A) = \frac{P(A \cap B)}{P(A)}$$ Reduces the denominator/sample space strictly to event $A$.
Event
Joint Probability 		Likelihood of two conditions/events occurring simultaneously. "both A and B", "simultaneously", "intersection" $$P(A \cap B) = P(A) \cdot P(B \mid A)$$ Represents the central overlapping region in a Venn diagram.
Event
Total Probability 		Sums the probabilities of an event $B$ across all mutually exclusive, exhaustive partitions $A_i$. "overall probability", "across all branches", "partitioned sources" $$P(B) = \sum_{i=1}^{k} P(B \mid A_i)P(A_i)$$ Weighted sum of conditional probabilities across all possible pathways (tree diagram).
Distribution
Bernoulli 		Single trial with exactly two outcomes (Success=1, Failure=0). "single trial", "pass/fail", "binary outcome" $$P(X=x) = p^x (1-p)^{1-x}, \, x \in \{0,1\}$$ $$\mu = p, \quad \sigma^2 = p(1-p)$$ Trial count is strictly $n = 1$. Base building block for Binomial.
Distribution
Binomial 		Count of successes $x$ in a fixed number $n$ of independent, identical trials. "fixed n trials", "x out of n", "constant probability p" $$P(X=x) = \binom{n}{x} p^x (1-p)^{n-x}$$ $$\mu = np, \quad \sigma^2 = np(1-p)$$ 4 BINS criteria: Binary, Independent, Number fixed ($n$), Same $p$.
Distribution
Poisson 		Count of rare, independent events occurring in a fixed interval (time/area/volume). "average rate (\lambda)", "per hour/minute/acre", "arrivals/defects" $$P(X=x) = \frac{e^{-\lambda} \lambda^x}{x!}, \, x \in \{0,1,2...\}$$ $$\mu = \lambda, \quad \sigma^2 = \lambda$$ No fixed upper limit on $x$. Mean equals Variance ($\mu = \sigma^2 = \lambda$).

Master Problem Decoding Flowchart

Follow the decision nodes below to classify any probability problem and select the correct formula.

🔍 WHAT IS THE PROBLEM ASKING YOU TO CALCULATE?
BRANCH A

A Random Variable / Count of Events

"How many successes?", "Number of arrivals?", "Pass or fail?"

1 Trial Only ($n=1$)
➔ BERNOULLI DISTRIBUTION
$P(X=x) = p^x(1-p)^{1-x}$
Fixed $n$ Trials + Constant $p$
➔ BINOMIAL DISTRIBUTION
$P(X=x) = \binom{n}{x} p^x (1-p)^{n-x}$
Rate $\lambda$ over Continuous Interval
➔ POISSON DISTRIBUTION
$P(X=x) = \frac{e^{-\lambda} \lambda^x}{x!}$
BRANCH B

Conditions or Partitioned Pathways

"Given that...", "Across all categories...", "Knowing $A$ occurred..."

Condition $A$ is KNOWN to have occurred
➔ CONDITIONAL PROBABILITY
$P(B \mid A) = \frac{P(A \cap B)}{P(A)}$
Overall odds across partitions $A_1...A_k$
➔ TOTAL PROBABILITY LAW
$P(B) = \sum P(B \mid A_i)P(A_i)$
BRANCH C

Combined Events ($A$ and/or $B$)

"Both $A$ and $B$", "Either $A$ or $B$", "Sequential draws"

Events do NOT affect each other ("With replacement")
➔ INDEPENDENT JOINT
$P(A \cap B) = P(A) \cdot P(B)$
Events affect each other ("Without replacement")
➔ DEPENDENT JOINT
$P(A \cap B) = P(A) \cdot P(B \mid A)$
Events CANNOT happen together
➔ MUTUALLY EXCLUSIVE
$P(A \cap B) = 0 \implies P(A \cup B) = P(A) + P(B)$

English-to-Probability Translation Dictionary

Convert word problem phrasing directly into standard set notation, Venn diagram regions, and executable rules.

Problem Phrase Symbolic Meaning Venn Diagram Target Actionable Formula
"Both A and B" / "Simultaneously" $A \cap B$ Center overlap region $P(A \cap B) = P(A) \cdot P(B \mid A)$
"At least one" / "A or B" $A \cup B$ Combined total area of both circles $P(A) + P(B) - P(A \cap B)$
"Given that B occurred" / "If B..." $A \mid B$ Ratio of Center Overlap to Circle B $\frac{P(A \cap B)}{P(B)}$
"Neither A nor B" $A^c \cap B^c$ Outside background area $1 - P(A \cup B)$
"A only" / "A but not B" $A \cap B^c$ Left crescent (Circle A minus overlap) $P(A) - P(A \cap B)$
"Exactly one of them" $(A \cap B^c) \cup (A^c \cap B)$ Both outer crescents combined $P(A \cup B) - P(A \cap B)$
"With replacement" Independent Draws Sample space size stays constant $P(A_1 \cap A_2) = P(A_1) \cdot P(A_2)$
"Without replacement" Dependent Draws Sample space reduces on draw 2 $P(A_1 \cap A_2) = P(A_1) \cdot P(A_2 \mid A_1)$
